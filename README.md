# 90-Day Cybersecurity Challenge

A focused, practical cybersecurity study challenge with a live countdown, 90-day roadmap, and progress tracking.

## Launch it

Open `index.html` directly, or enable **GitHub Pages**:

1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

## Features

- Live 90-day countdown
- Daily clock showing elapsed time and remaining time
- 90 daily challenge cards
- Persistent completion tracking with `localStorage`
- Editable challenge start date
- Responsive, accessible interface
- Responsible-lab reminders

## Learning structure

- **Days 1–30:** Foundations, networking, Linux, and Python
- **Days 31–60:** Defensive security, SIEM, web security, and incident response
- **Days 61–90:** Penetration-testing workflow, automation, portfolio work, and review

Use only systems you own or have explicit permission to assess. Never include credentials or sensitive evidence in this repository.
